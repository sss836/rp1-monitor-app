# RP1 整机上位机 0.4.3

本版合入原生平台接入、可恢复的提交队列和工厂结果追溯。Ubuntu 24.04 amd64 安装说明见 [PC_DEB.md](PC_DEB.md)。`0.4.3` 高于 `0.4.2+p0p1.20261109.1` 候选版本；包安装本身不重启上位机或接管正在运行的记录。

- 顶部按需登录平台，本地工作台可直接使用。研发原始记录和工厂结果分别提交，权限与审批由平台判定。
- 工厂汇总保留固定 17 列 CSV，并生成同名追溯清单。原始结论、复测来源和人工更改历史留档，改判记录前后值及理由。
- 提交只处理所选任务；批量重试按平台、账号和来源筛选。明确需要人工核对的任务隔离并保留证据，临时故障可用原幂等键恢复。
- 带清单提交先接收 CSV，再上传原始清单；清单确认前仍为待处理，丢回执后只续传未确认阶段。

## 平台兼容性

旧版平台仍能处理没有伴随清单的旧 17 列 CSV。带清单的新导出需要平台支持工厂归档的 `trace_sha256` 参数，以及 `POST /api/v1/factory/robot-result-archives/{id}/trace`。当前现场 `3.0.23-samples1` 尚未提供这两个入口；新带清单提交会被拒绝并保留在本机待核对任务中。不要移走清单来绕过校验。配套平台就绪后，在原账号和原平台下选中原任务重试。

此发布只更新电脑上位机仓库和安装包。本地测试、保存、导出与平台追溯上传独立。提交前仍须由人员核实；收到 CSV 或清单不等于工厂批准，也不产生 MTBF 暴露。

升级前核对未完成任务并备份本地状态目录；旧程序无法正确处理新增的两阶段追溯任务。软件与隔离接口验证不能代替实机通信、持续测试和工厂审核验收。
