# 物理速度门与接触判据只读审查

2026-11-01。按最终范围复核 `calibration_check.py`、`motor_control_runtime.py` 及映射。未修改源码或测试，未连接机器人、SSH、CAN 或电机 SDK；仅写报告和受托的 `/tmp/rp1-unloading-boundary-repro.py` 假驱动复现脚本。

## 结论

当前未发现本轮遗留阻断项。

- False 标定路径的固定物理 20°/s 中止门已移除，自适应限速与虚拟时钟草稿也已撤回。逻辑速度仍按本次确认参数执行；此前报告中的物理硬门描述属于历史行为。
- 卸载识别同时考虑阶段变化前后。旧实现会将 `confirm_stop→retreat` 当期的新鲜实际角度卸载误算成运动速度；修复后该边界仍正确卸载，并使用实际反馈选择物理角支路。
- False 接触检测使用实际位置窗口和持续力矩条件；不再要求先移动 0.2°，也不再要求窗口内目标至少推进 0.02°。实际跨度上限为 0.05°，默认窗口 0.5 秒，配置保存在 `contact_detection` 中。目标到达模型端点不能替代实际反馈判据，结果仍为候选。

## 独立验证

24/28 轴各验证 7 个场景，共 14 个；控制周期循环使用 17、43、11、29、50ms。

| 实际反馈及力矩场景 | 结果 |
|---|---|
| 初始静止，力矩持续升至接触及升幅阈值 | 0.54 秒后候选 |
| 实际持续以 0.3°/s 移动，力矩升高 | 无候选，超时未检出 |
| 搜索 0.01°/s、实际静止、力矩升高 | 0.54 秒后候选 |
| 已有高力矩但无新增升幅 | 无候选 |
| 单个力矩尖峰 | 无候选 |
| 力矩低于接触阈值 | 无候选 |
| 非耦合轴 ±1 原生编码步抖动、力矩升高 | 可形成候选 |

所有冻结目标均等于当期实际位置，`calibration_passed=None`。

另用 100ms 反馈更新、20ms 控制周期复现旧阶段误报：电机反馈变化 0.496895°，实际反馈速率约 4.968952°/s，却被旧门按控制间隔算成 24.844760°/s。修复后 24/28 轴均不再因此中止。该复现与闭链映射实际放大目标速度是不同路径，现场截图缺少阶段和逐电机时间数据，不能唯一归因。

以上均为软件模拟证据，不是实机运动、机械止挡或标定验收。旧内存控制会话不会随本地源码热更新，应用修改需要结束旧会话后重新连接；本审查未代操作机器人。
